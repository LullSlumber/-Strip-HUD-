# FusionStrip

跑在 SystemUI 进程里的 LSPosed 悬浮性能监视条模块，横条（Strip）形态：单行覆盖屏幕上/下边缘，显示 FPS、帧率图、GPU、CPU、温度、电池、网速、时钟等指标。

由 [NexusFloat](https://github.com/YeLuoYuXiang/NexusFloat)（GPL-3.0）衍生重构，横条设计语言来自 [Bannerlator](https://github.com/The412Banner/Bannerlator) 的 FusionHUD Strip 模式（FusionHUD © The412Banner，GPL-3.0）。

## 构建

GitHub Actions：push 到 `fix/**` / `ci/**` 分支自动构建签名 release APK，挂到 `ci-build` rolling release。
